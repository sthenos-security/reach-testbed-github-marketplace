# Security policy

## Reporting a vulnerability

Please report security vulnerabilities in REACHABLE privately. Do not open a
public issue.

- **Preferred:** use GitHub's private vulnerability reporting —
  [Report a vulnerability](https://github.com/sthenos-security/reach-testbed-github-marketplace/security/advisories/new)
  (Security tab → "Report a vulnerability").
- **Email:** <support@sthenosec.com> with "SECURITY" in the subject.

Include the affected component and version, steps to reproduce, and the impact
you observed. We acknowledge reports within 3 business days and keep you
informed until the issue is resolved. Please give us a reasonable time to fix
the issue before any public disclosure.

## Scope

This repository and the REACHABLE components it ships or installs. Findings that
REACHABLE reports about *your* code are product output, not vulnerabilities in
REACHABLE — please send those to <support@sthenosec.com> as normal support.
